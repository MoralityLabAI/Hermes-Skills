# Overleaf Pack

This directory is the Overleaf-ready source package for:

`TRM-MCP: Tiny Recursive Controllers for Structured Tool Memory`

Upload the contents of `TRM_MCP_overleaf.zip` to Overleaf and compile `main.tex`.

## Included

- `main.tex`: self-contained manuscript with TikZ/pgfplots figures.
- `references.bib`: local artifact bibliography.
- `tables/*.csv`: source CSVs used to build the manuscript figures and tables.
- `figures/*.svg`: original SVG figure sources from the paper seed, included as supplemental source artifacts. The manuscript does not require SVG conversion.

## Claim Boundary

The recovered Primehub schema measurement shows exact-structure reward gains with higher token use. It does not show token-cost reduction. The Postgres DB lookup efficiency figure is an analytical model, not measured latency or token telemetry.
